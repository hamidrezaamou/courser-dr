این پوشه را روی ریشهٔ لاراول هاست (همان‌جا که پوشهٔ app و routes هست) آپلود کنید.
فایل‌ها را جایگزین کنید. .env و storage را دست نزنید.

بعد در Terminal سی‌پنل:
php artisan optimize:clear

اگر route:cache قبلاً زده‌اید:
php artisan route:cache

این بسته هم سایت را کامل می‌کند هم API دسکتاپ را:

سایت
- منوی هدر بدون «راهنما» (مثل برنامه دسکتاپ)
- ماژول‌های پیشرفته با اولین بارگذاری روشن می‌شوند
- CORS برای API موبایل/دسکتاپ

API دسکتاپ
- پیگیری با فیلتر، کارت و نتیجه مثل سایت
- تنظیمات پیگیری: فهرست، الگو، مرحله
- ویرایش نوبت، تایم+پیامک، VCF، پروفایل، چاپ

بعد از آپلود برنامه را روی http://127.0.0.1:1420 با Ctrl+F5 باز کنید.
