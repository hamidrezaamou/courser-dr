آرشیو بیمار — نسخه ویندوز ۰.۱.۰
================================

این پوشه را روی فلش یا از طریق شبکه به ویندوز مقصد ببرید.

روش ۱ — نصب روی ویندوز جدید (پیشنهادی)
- فایل Mramo_0.1.0_x64-setup.exe را اجرا کنید.
- نصب برای کاربر فعلی است و معمولاً رمز ادمین نمی‌خواهد.
- بعد از نصب، میانبر «Mramo» ساخته می‌شود. عنوان پنجره «آرشیو بیمار» است.

روش ۲ — قابل‌حمل بدون نصب
- پوشه portable را هر جا کپی کنید (دسکتاپ، فلش، پوشه مشترک).
- Mramo.exe را اجرا کنید. نصب لازم نیست.

ورود
- همان کد ملی و رمز سایت https://mramo.ir
- برای ورود اول اینترنت لازم است. بعد از آن بخشی از کار آفلاین می‌ماند.

پیش‌نیاز ویندوز مقصد
- ویندوز ۱۰ یا ۱۱، ۶۴ بیتی
- معمولاً WebView2 همراه ویندوز است. اگر پنجره باز نشد، «Microsoft Edge WebView2 Runtime» را از سایت مایکروسافت نصب کنید.

اگر ویندوز برنامه را ناشناس دانست
- روی More info / اطلاعات بیشتر بزنید و Run anyway / اجرا را انتخاب کنید.
- فایل امضای دیجیتال مایکروسافت ندارد؛ این هشدار طبیعی است.
