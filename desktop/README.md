# اپ ویندوز «آرشیو بیمار»

ایستگاه کاری دسکتاپ برای منشی و پزشک. ظاهر نزدیک به اپ اندروید است، ولی شِل سه‌ستونه و میان‌بر کیبورد دارد.

صفحه از **دادهٔ محلی** باز می‌شود. هاست (`https://mramo.ir`) فقط برای ورود اول و همگام‌سازی است.

## الان چه چیزهایی کار می‌کند

- ورود با کد ملی و رمز وب (همان API موبایل)
- خانه، جستجوی بیمار، ثبت بیمار، پرونده/تایم‌لاین، بُرد و تغییر وضعیت
- ثبت ویزیت و عمل (همان جریان موبایل) با صف آفلاین؛ اگر اسلات پر باشد سرور رد می‌کند
- اگر نت قطع شود، آخرین دادهٔ کش‌شده نشان داده می‌شود
- `Ctrl+K` جستجو، `F2` ثبت بیمار، `F3` بُرد، روی پرونده `F4` ویزیت و `F5` عمل

تایم‌ها، چاپ، حسابداری، ادمین و HIS در منو هستند ولی هنوز «فاز بعد»اند.

## اجرا در مرورگر (همین حالا)

از پوشهٔ `desktop`:

```
npm install
npm run dev
```

آدرس: `http://localhost:1420`

پروکسی Vite درخواست‌ها را به هاستی که در فرم ورود می‌نویسید می‌فرستد.

## اجرای پنجرهٔ ویندوز (Tauri)

پیش‌نیاز: [Rust](https://www.rust-lang.org/learn/get-started) و WebView2 (ویندوز ۱۰/۱۱ معمولاً دارد).

```
npm run tauri dev
```

ساخت نصب‌کننده:

```
npm run tauri build
```

## اتصال
